Read these files before architecture, diagnosis, TDD, or planning work:

- `docs/project-map.md`: current module map and known friction.
- `docs/superpowers/specs/2026-06-19-agent-mcp-hardware-console-design.md`: current MCP hardware-console architecture.
- `docs/archive/legacy-web-agent/`: archived legacy web-agent docs retained for historical context only.

ADRs should live under `docs/adr/` when durable architectural decisions are
recorded.
